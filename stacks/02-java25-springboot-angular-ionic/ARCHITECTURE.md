# Stack 02 — Java 25 / Spring Boot + Angular + Ionic (architecture)

Enterprise cross-platform reference: one Spring Boot API, an Angular web
client, and an Ionic+Capacitor mobile shell, all speaking the repository
envelope contract (docs/PRODUCT_REQUIREMENTS.md §7).

## 1. Layering

```
stacks/02-java25-springboot-angular-ionic/
├── backend/    Java 25 + Spring Boot 4.1  (Maven, JUnit 5 — VERIFIED)
├── web/        Angular 20 standalone       (vitest + ng build — VERIFIED)
├── mobile/     Ionic 8 + Capacitor 7 shell (UNVERIFIED — no mobile SDK)
└── stack.json  manifest (maturity: scaffolded)
```

**API and web live on SEPARATE prefixes**: the backend serves `/api/v1/**`
only; the Angular app is served by its own dev server / static host and is
never proxied through the API. The only shared surface is the JSON envelope.

## 2. Backend (verified)

- **Boot**: `Stack02Application`, servlet stack, H2 (dev/test) or PostgreSQL
  (prod profile) behind Flyway (`V1__users.sql`).
- **Envelope**: `web/ApiResponse` — `{success, data, error{code,message,
  details}, meta{timestamp, execution_ms?, request_id}}` on every response.
- **Correlation**: `web/RequestIdFilter` resolves the request id ONCE per
  request: an incoming `X-Request-Id` matching `[A-Za-z0-9-]{1,64}` is
  echoed in the header and in `meta.request_id`; anything else is replaced
  by a server-generated UUID. Header and body can never diverge. Client
  input is validated before reuse, never reflected verbatim.
- **Throttle (config-driven)**: `config/ThrottleProperties`
  (`app.throttle.*`) feeds `AuthService` — max FAILED logins per identity
  (normalized email + client IP) per fixed window; exceeding it throws
  `RateLimitedException`, mapped to HTTP 429 with `Retry-After` in seconds
  from `app.throttle.retry-after-seconds` (default 60; operators tune it
  without code changes). Only FAILED attempts consume the budget; a
  successful login resets the tally. With no trusted proxies configured
  (default) `X-Forwarded-For` is IGNORED — the TCP peer is the client.
- **Normalize-before-unique**: `AppUserDetailsService.normalize` (trim +
  lowercase) runs BEFORE every unique check, insert, and lookup; the
  persistence layer (`users.email UNIQUE`) only ever sees canonical values,
  so `MixedCase@Example.com` and `mixedcase@example.com` are one account.
- **Auth**: server-side sessions in an opaque HttpOnly, SameSite=Lax cookie
  (`STACK02_SESSION`, 30 min). CSRF: double-submit cookie (XSRF-TOKEN →
  X-XSRF-TOKEN), enforced on all state-changing endpoints except the
  pre-session register/login (documented trade-off). Unknown email and wrong
  password are indistinguishable (INVALID_CREDENTIALS; no enumeration).
- **Screens**: `HomeController` (screen 3) and `AlgorithmController`
  (screen 4) with the fixed `AlgorithmCatalog` (reverse / palindrome /
  fizzbuzz / wordcount), bounded input (10 000 chars, defense in depth:
  bean validation AND engine), measured `execution_ms` reported separately
  from theoretical Big-O `complexity`.

### FORBIDDEN here (stack rules)

- **SSE / WebSocket / any server push**: clients refresh by POLLING only
  (Home polls `/api/v1/home` every 15 s; the workbench is request/response).
- Test literals are dictionary-style words (`Harbor Lantern 42`); no
  leetspeak, no high-entropy strings (GitGuardian entropy rule).

## 3. Web (verified)

Angular 20 standalone components, four routed screens
(`web/src/app/app.routes.ts`): register → login → home → algorithm
workbench. `api/client.ts` unwraps the envelope, maps non-2xx to
`ApiError{code,status,details}`, echoes the CSRF cookie on POST, and tracks
the last `X-Request-Id` for correlation. Home demonstrates the documented
polling cadence (15 s) with explicit loading/error/unauthorized states.
Tests: `web/src/web.client.test.ts` (vitest + jsdom, 12 tests; components
exercised by direct instantiation with a stubbed Router, fetch mocked at the
boundary; templates verified by the AOT strictTemplates `ng build` gate);
production bundle verified with `ng build` (exit 0).

## 4. Mobile (implemented, UNVERIFIED)

`mobile/` is a thin Capacitor 7 shell around the SAME Angular app:
`capacitor.config.json` pins the app id and `https` scheme; the web build is
synced into `www/`. No native project folders are committed (generated by
`cap add`). Nothing here was compiled or run — no Android SDK / Xcode in the
reference environment; see verification.md §UNVERIFIED.
