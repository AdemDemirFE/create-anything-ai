# Stack 02 — mobile shell (Ionic + Capacitor)

Thin native shell around the SAME four-screen Angular app (`../web`). The
mobile client:

- reuses the web build output (copied into `www/` by `npx cap sync`);
- talks to the identical `/api/v1` envelope contract;
- replays the session cookie from the Capacitor WebView
  (`server.androidScheme: https` in `capacitor.config.json`);
- stores no secrets in plain preferences (`@capacitor/preferences` is only
  used for non-sensitive UI state).

## Status: UNVERIFIED (no mobile SDK)

The reference environment has no Android SDK / Xcode, so NOTHING in this
directory was compiled or run on a device/emulator. CI deliberately does NOT
include a mobile suite (see `.github/workflows/ci.yml` stack-smoke matrix and
`../verification.md` §"UNVERIFIED"). To verify locally:

```bash
# from ../web
npm run build            # produce dist/stack02-web/browser
# from here
npm install
npx cap add android      # requires the Android SDK
npx cap sync             # copies the web build into android/
npx cap open android     # open Android Studio
```

Native project folders (`android/`, `ios/`) are intentionally NOT committed:
they are generated by `cap add` and pinned by `capacitor.config.json`.
