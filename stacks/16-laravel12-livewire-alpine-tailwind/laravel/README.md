# Stack 16 — Laravel 12 backend (TALL web + /api/v1)

The Laravel application for the four-screen journey: Livewire 3
full-page components + Alpine 3 + Tailwind CSS 3 for the browser, and a
session-cookie-authenticated `/api/v1` JSON API (stack envelope
`{ ok, data, error, requestId }`).

Setup, tests, and architecture: see the parent `../README.md` and
`../ARCHITECTURE.md`. Verification evidence: `../verification.md`.
