# Stack 15 — Laravel 12 backend (web + /api/v1)

The Laravel application for the four-screen journey: Inertia 2 + Vue 3
pages for the browser, and a session-cookie-authenticated `/api/v1` JSON
API (stack envelope `{ ok, data, error, requestId }`) shared with the
Flutter client in `../mobile/`.

Setup, tests, and architecture: see the parent `../README.md` and
`../ARCHITECTURE.md`. Verification evidence: `../verification.md`.
